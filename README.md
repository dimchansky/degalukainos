# Degalų kainos Lietuvoje

Šioje saugykloje yra **tik sugeneruotas puslapis** — jį rasite `gh-pages` šakoje,
o veikiantį tinklalapį adresu **https://dimchansky.github.io/degalukainos/**.

Puslapis rodo degalų kainas visose Lietuvos degalinėse: kainą galima matyti
spalva žemėlapyje, sąraše ir pagal vietoves. Duomenys — Lietuvos energetikos
agentūros, atnaujinami du kartus per darbo dieną.

Pirminis kodas yra privačioje saugykloje. `gh-pages` šaka perrašoma iš naujo per
kiekvieną paskelbimą, todėl joje visada yra tik vienas commit'as: tai puslapio
kopija, o ne jo istorija.

---

This repository holds **only the built page** — in the `gh-pages` branch, served
at **https://dimchansky.github.io/degalukainos/**. The source lives in a private
repository. `gh-pages` is force-pushed on every publication and always holds a
single commit: a copy of the current page, not a history of it.
